# Rhode Sales Analytics Dashboard | Predictive Analytics Using Historical Data

## Overview

This project is an end-to-end sales analytics solution built using Python, MySQL (Aiven Cloud), and Power BI. The Rhode sales dataset was imported from Excel into an Aiven MySQL cloud database using Python in Google Colab. The data was then connected to Power BI, where data transformation, cleaning, visualization, and six-month sales forecasting were performed to generate meaningful business insights.

---

## Project Objectives

* Import sales data into a cloud-based MySQL database.
* Perform data transformation and cleaning.
* Analyze sales performance using interactive dashboards.
* Identify trends, top-performing products, and customer behavior.
* Forecast sales for the next six months.

## Project Workflow

1. Obtained the Rhode sales dataset in Excel format.
2. Created a MySQL cloud database using Aiven.
3. Used Google Colab with Python and Pandas to import the Excel dataset into the Aiven MySQL database.
4. Connected Power BI Desktop to the MySQL database.
5. Performed data transformation and cleaning using Power Query.
6. Built an interactive dashboard with KPIs and visualizations.
7. Applied Power BI forecasting to predict sales for the next six months.
8. Generated business insights to support data-driven decision-making.
